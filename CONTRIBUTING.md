# Contributing to ISO 9001:2026 Gap Analysis Tool

Thank you for your interest in this project! This tool is designed to help quality professionals assess their readiness for the ISO 9001:2026 transition.

## Reporting Issues

- Use [GitHub Issues](https://github.com/Lynx-Caden/iso9001-2026-gap-tool/issues) to report bugs, suggest features, or ask questions.
- Please include: Excel version, OS, steps to reproduce (for bugs), and screenshots if applicable.

## Bug Reports

We use GitHub Issues to track bugs. Before filing a new issue:
1. Check that the issue hasn't already been reported
2. Describe the bug clearly with steps to reproduce
3. Specify your environment (Excel 365/2019/LibreOffice/Google Sheets, OS)

## Feature Requests

- Open an Issue with the "enhancement" label
- Describe the feature and why it would be useful
- Include any relevant references to ISO 9001:2026 requirements

## Code of Conduct

- Be respectful and constructive
- Focus on the content, not the person
- This is a professional tool for quality management — keep discussions professional
